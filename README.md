# 🌟 JetSpin
A mesmerizing canvas-based animation project built with Jetpack Compose.
JetSpin is an Android project that demonstrates the beauty of mathematical patterns through the smooth rotation of 3000 circles. This project is inspired by a similar concept on iOS and showcases the power of Jetpack Compose's Canvas API for creating dynamic and visually stunning animations.

## <br/><br/>🚀 Features
• Mathematical Beauty: Harnesses trigonometric functions to create spiraling patterns.
• Smooth Animations: Built with Jetpack Compose for seamless rendering.
• Highly Configurable: Easily adjust parameters like rotation speed, circle size, and colors.
• Custom Color Patterns: Each circle's hue is dynamically calculated to create a beautiful gradient effect.

##💡 How It Works
JetSpin uses:
• Canvas API: To draw 3000 circles on the screen dynamically.
• Mathematical Functions: Trigonometry (cos, sin) to create spirals and rotations.
• State Management: Updates the rotation and rendering smoothly over time.
Each circle's position and color are calculated using trigonometric transformations and hue-based color generation.
